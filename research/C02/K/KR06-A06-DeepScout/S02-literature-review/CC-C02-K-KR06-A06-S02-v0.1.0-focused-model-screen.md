# Focused primary-source screen (not exhaustive)
Audio: [YAMNet](https://www.tensorflow.org/hub/tutorials/yamnet) 521 general event tags; [CLAP](https://github.com/LAION-AI/CLAP) open vocabulary audio/text contrastive; [BEATs](https://github.com/microsoft/unilm/tree/master/beats) acoustic tokenizer supervision; [PANNs](https://arxiv.org/abs/1912.10211) AudioSet CNN; [AudioMAE](https://github.com/facebookresearch/AudioMAE) masked spectrogram reconstruction; [HuBERT](https://huggingface.co/facebook/hubert-base-ls960) masked cluster label speech prediction; [WavLM](https://huggingface.co/microsoft/wavlm-base-plus) masked speech denoising/speaker-aware features; [openSMILE](https://audeering.github.io/opensmile/about.html) acoustic/prosodic descriptors; [AST](https://github.com/YuanGongND/ast) spectrogram transformer. Neither speech embeddings nor sound classification establish intent, sarcasm or editorial value.
Visual: [SigLIP](https://huggingface.co/google/siglip-base-patch16-224) image-text sigmoid pair loss; [CLIP](https://github.com/openai/CLIP) contrastive frame embeddings; [VideoMAE](https://github.com/MCG-NJU/VideoMAE) masked tube reconstruction; [V-JEPA 2](https://github.com/facebookresearch/vjepa2) latent predictive feature learning; [open-world state change](https://openaccess.thecvf.com/content/CVPR2024/html/Xue_Learning_Object_State_Changes_in_Videos_An_Open-World_Perspective_CVPR_2024_paper.html) state representation and temporal localization; [GEBD](https://github.com/MCG-NJU/GEBD) boundary detection not value; [ActionFormer](https://arxiv.org/abs/2202.07925) temporal action localization; [PDVC](https://github.com/ttengwang/PDVC) dense event localization/captioning; [STEPs](https://github.com/anshulbshah/STEPs) procedural key steps, task prior mismatch; [Qwen2.5-VL](https://huggingface.co/Qwen/Qwen2.5-VL-3B-Instruct) selective VLM comparator, license gate. GEBD/PDVC/STEPs leads inherited from KR01/KR04, not reaudited here.
Adaptive: [AdaFrame](https://openaccess.thecvf.com/content_CVPR_2019/html/Wu_AdaFrame_Adaptive_Frame_Selection_for_Fast_Video_Recognition_CVPR_2019_paper.html) trained recurrent controller + global memory for classification; [adaptive keyframe sampling](https://openaccess.thecvf.com/content/CVPR2025/html/Tang_Adaptive_Keyframe_Sampling_for_Long_Video_Understanding_CVPR_2025_paper.html) balancing relevance and coverage (query task); [VideoAgent](https://arxiv.org/abs/2403.10517) query-driven iterative frames, author-reported 8.4 and 8.2 frames average on EgoSchema/NExT-QA; this excludes the distinction between initial indexing and LLM viewed frames, not evidence of cheap open-ended discovery; [distinct VideoAgent memory](https://videoagent.github.io/) temporal/object memory and tools; [SoccerNet](https://www.soccer-net.org/tasks/action-spotting) event time localization at known action taxonomy; [Less Is More](https://vision.cs.utexas.edu/projects/highlights/) weak duration supervision, editing/domain bias. [ImageBind](https://github.com/facebookresearch/ImageBind) shared multimodal embedding lead, checkpoint/rights not traced. [ClipSense](https://github.com/NamanBhatia-NB/ClipSense_AI) peer KR04-F007/F008 describes consensus bias and missing visual/prosody; candidate union instead. [Moment-DETR](https://github.com/jayleicn/moment_detr) query-conditioned saliency not open-world interest. Literature screening only except pinned source traces in S03. No cross-task mAP comparisons or claims of current SOTA.
