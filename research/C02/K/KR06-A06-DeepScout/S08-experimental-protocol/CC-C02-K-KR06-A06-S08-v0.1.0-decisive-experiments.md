# Experiments (proposed, not executed except E000)
Follow ChompBench independent source annotations: https://github.com/CrypticLuminary/AI_Clipper-Chomp-Chomp-/blob/5d4b84f45241e14d31934aee1ff3b2960511022b/docs/cycle2/annotation-guidelines.md . Freeze creator-disjoint split and independent full-source event roster before candidates, include empty-event sources, label core and essential, required modality, quiet/silent, event identity, setup/payoff, disagreement. Two independent reviewers plus adjudication; compare paired by creator, bootstrap 95% CI, report denominators and full misses; strata may overlap. Predeclared thresholds below are proposed engineering gates, not established statistical power; if fewer samples report uncertainty and collect more. Core>=80% interval covered by one proposal; essential/context distinct; independent approval precision not inferred from time overlap. Equal K, unique union footage, model invocations and total processing time; if all cannot be matched simultaneously use Pareto curves. Profile on same hardware and identical cache protocol; no paid calls. 
### E001
- Hypothesis: Semantic tags increase recall of non-energy acoustic events; prosody helps only as context
- Baseline: Existing RMS/transient + Director text
- Model: google/yamnet/1; CLAP HTSAT-tiny 630k-audioset-best.pt; BEATs iter3+ AS-finetuned exact file to pin; eGeMAPSv02; microsoft/wavlm-base-plus frozen mean+std probe
- Features: 16k 0.96/0.48 YAMNet; CLAP 48k 10s/5s selective; independent ASR text; compare transcript only, prosody only, fused
- Budget: 40 candidates/h; continuous 7500 YAMNet patches/h approx; CLAP <=24 windows/h; same downstream verification cap
- Metrics: Acoustic event mAP/F1 and core recall by subtype, quiet speech recall, speaker-attribution error
- Sample: Minimum 50 positive acoustic events + 50 hard negatives across holdout creators, otherwise descriptive
- Cost: Decoded audio minutes, model ms/patch, VRAM, wall time; local only
- Proposed acceptance: at least +10pp recall on acoustic subset, no more than 5pp quiet speech drop; paired CI required before promotion
- Failure: Background/game laughter false attribution or no gain at matched cost

### E002
- Hypothesis: Hybrid floor+adaptive refinement rescues short silent events
- Baseline: Uniform 900 frame encodes/h
- Model: google/siglip-base-patch16-224
- Features: 224px frames, 450 uniform floor/h at 8s spacing + 450 triggered by 2fps luma/motion probes, scene changes, embedding novelty and random rescue; log proxy decode cost; compare pure uniform and shot/motion only
- Budget: 900 unique image encodes/h, equal decoded timeline and 40 proposals/h; vary frame budget 450/900/1800
- Metrics: Silent core recall, observation hit by duration, duplicates, cost
- Sample: 50 silent events, incl >=15 under 2s, plus negative idle regions
- Cost: Sequential proxy decode, 900 encodes, actual seek overhead; no paid compute
- Proposed acceptance: at least +10pp silent recall at same total cost or same recall >=20% lower cost
- Failure: Motion false positive or blind gaps, lower brief-event recall

### E003
- Hypothesis: Temporal sequences disambiguate action order vs isolated frames
- Baseline: Single SigLIP frames and unordered mean embeddings
- Model: MCG-NJU/videomae-base-finetuned-kinetics; facebook/vjepa2-vitl-fpc64-256 challenger
- Features: For each proposal 16 frames @2fps across 8s, compare ordered vs reversed vs shuffled; before/after pairs; use same raw frames, held-out action/state descriptions
- Budget: 24 windows/h x16 frames; V-JEPA 64 frames only separate cost stratum, same source span; 40 candidates/h
- Metrics: State-transition and ordering accuracy; core recall, latency
- Sample: 50 paired order-dependent and 50 order-independent examples
- Cost: Temporal encoder GPU time + decoding vs single frame encodes; no paid
- Proposed acceptance: at least +10pp on order-dependent subset and no increase in hallucinated transitions >5pp
- Failure: Cannot identify outcomes in gameplay, no gain or excessive cost

### E004
- Hypothesis: Independent union avoids silent/quiet losses from consensus
- Baseline: Require >=2 distinct available lanes supporting linked proposal
- Model: Same fixed cached Director, YAMNet, SigLIP and optional chat evidence; RRF/union
- Features: Same evidence and candidate IDs, gold links forbidden, contradictory evidence flag separate
- Budget: K=20/40/60 per hour; match unique footage and provider budget
- Metrics: Core recall by single/multi lane, false candidate windows, missing modality degradation
- Sample: Full test set incl 50 single-lane events each dialogue/vision if available
- Cost: Identical feature extraction; report selection CPU separately
- Proposed acceptance: Single-lane recall +10pp with all-event recall noninferior (margin 5pp)
- Failure: Union swamps candidate pool; grouping oracle leakage

### E005
- Hypothesis: Bounded lane quota reduces starvation without excessive loss
- Baseline: Lane order truncation, equal quota, pure RRF
- Model: No new model; RADAR-X same evidence plus Keystone candidate collector
- Features: Independent ranked lane lists, deterministic links, 1 eligible lane floor then RRF fill; test zero budget/ties/empty/unavailable/overlap
- Budget: K=10/20/40/60 per hour; same candidate context footage cap 15 min/h primary
- Metrics: Core recall, worst lane recall, exclusions, duplicate identity rate, time/footage
- Sample: Full holdout plus skewed lane counts and missing-chat ablation
- Cost: O(NlogN + KN) naive selection; measure CPU and peak RAM
- Proposed acceptance: Worst-lane recall +10pp vs lane order, overall within 5pp of RRF; retain distinct overlaps
- Failure: Quota spent on junk; low-budget regression as DS01

### E006
- Hypothesis: Independent visual coverage rescues events beyond audio-first trigger
- Baseline: Same visual model called only around ASR/energy proposals
- Model: SigLIP base 224 same cache/preprocess
- Features: Audio-triggered frames vs independent uniform+adaptive frame budget; same audio evidence and final ranker
- Budget: 900 image encodes/h; 40 proposals/h; 15 unique footage min/h; equal verification calls
- Metrics: Silent/no-chat core recall, quiet speech recall, visual misses by duration
- Sample: 50 silent events and 50 speech events with missing chat strata
- Cost: Measure same hardware total decode + forward; no paid
- Proposed acceptance: at least +10pp silent recall; quiet recall no worse than 5pp
- Failure: No independent rescue benefit or coverage cost disproportionate

### E007
- Hypothesis: Semantic perception improves existing discovery under matched cost
- Baseline: Pinned Director baseline and RADAR-X RRF; A/B/C/D if feasible
- Model: YAMNet/CLAP/SigLIP/VideoMAE with versions above; D Qwen2.5-VL-3B-Instruct local checkpoint/license gate
- Features: Same authorized VODs and source clocks; ablations add one producer at time; compare architecture A with B/C at matched runtime and K
- Budget: K=40/h; 15 unique footage min/h; <=24 escalations/h; same Director call budget; compute curve matched measured walltime
- Metrics: Core recall>=80% interval coverage by one proposal per ChompBench; essential-span coverage separate; review precision and human preference independent
- Sample: 24 VODs target 6 dev/6 validation/12 heldout, creator-disjoint, two independent annotators; >=50 events per priority stratum or widen sample
- Cost: Stage timings, cache hit rates, PTS, energy/VRAM, actual provider fees only if explicitly authorized
- Proposed acceptance: Overall +10pp recall and quiet/silent each +10pp vs pinned baseline, no more than 5pp precision decline; paired creator bootstrap lower bound >0 for improvement
- Failure: Insufficient sample, no rights, failed runtime, poorer recall or cost cap violation
