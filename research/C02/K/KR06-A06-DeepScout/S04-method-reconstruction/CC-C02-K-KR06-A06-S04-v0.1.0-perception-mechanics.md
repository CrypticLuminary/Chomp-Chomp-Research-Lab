# Mechanisms
Acoustic: classify each patch/window, retain multilabel score vector and valid interval, threshold on dev per class; contiguous spans plus min-gap, avoid duplicate overlapping windows. Novelty: cosine distance 1-cos(e_t, robust running centroid) with reset at scene cuts; clip outliers not events without evidence. CLAP text prompt scoring max/mean paraphrase similarity, prompt sets versioned; negative label margins not calibrated probabilities. Speech: ASR meaning and discourse independent of loudness; pitch range, voiced ratio, pause/turn timing, energy normalized by speaker/track; WavLM/HuBERT frozen embedding only with trained/validated head. Speaker attribution unknown on mixed track. Neutral delivery is not negative evidence.
Vision: low-res sequential decode, uniform lattice floor, shot/motion and separate facecam/gameplay ROI when known, image embedding delta, state pair t-before/t-after, short ordered sequence for temporal model. State-change can be a meaningful event even if global motion low. Minimum observation hypotheses: 0.1–2s brief transient requires high-rate probes; 2–8s action use 8–16 frames; 5–30s setup/payoff use temporal windows and longer memory; dialogue callback can require minutes. No universal duration. Camera cuts and overlay changes are confounders. Detect sudden semantic difference but do not equate surprise to interestingness.
Uniform coverage: random phase probability min(1,d/Delta) under perfect visibility, continuous interval d, lattice interval Delta. E000 probe sweeps 28 duration/gap combinations; analytic equivalence only, not real event detector. See S08. Fixed lattice cannot guarantee short transients. High-rate cheap motion proxy still blind to static semantics; random rescue and floor reduce not eliminate misses.
