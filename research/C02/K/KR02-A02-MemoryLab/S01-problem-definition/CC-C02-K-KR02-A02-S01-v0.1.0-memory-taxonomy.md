# Memory taxonomy and problem definition — v0.1.0
PROPOSED. Preserve the distinction between evidence memory (immutable observation), retrieval (candidate evidence selection), reasoning (test interpretations), and editorial decision (KR04/05).
- Working memory: bounded candidate-specific evidence and open requirements, not whole VOD.
- Episodic memory: time-local events and dialogue units, possibly overlapping/nested.
- Semantic memory: attributed claims and provisional generalizations; version rather than overwrite contradictions.
- Hierarchical memory: L0 observations, L1 acts, L2 events, L3 episodes, L4 references. Hierarchy is an access path, not a forced partition.
- Temporal memory: source-relative interval index; range reads and before/after constraints.
- Associative/entity memory: speaker-scoped entity mentions, aliases, uncertain matches; do not merge people on name alone.
- Graph memory: typed, evidence-backed dependency hypotheses; preserve direction and provenance. A graph is optional until retrieval ablation justifies it.
- Compressed memory: extractive/abstractive summaries with recoverable raw IDs, not evidence substitutes. Embeddings cannot recover verbatim quotes.
- External/agentic memory: structured search, evidence inspection, explicit uncertainty, finite budgets.
- Long-context attention: baseline on all available transcript when affordable, not evidence of visual coverage.
The task is candidate-conditioned query creation, not question-answering alone. An offline VOD permits both directions; live mode must apply availability cutoff. Do not equate unseen with absent.
