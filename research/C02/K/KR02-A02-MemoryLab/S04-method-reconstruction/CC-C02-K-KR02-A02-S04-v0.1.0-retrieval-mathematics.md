# Mathematical reconstruction — PROPOSED comparison
Let N evidence units, d embedding dimension, E graph edges, B token budget, k retrieved units. Each unit u=(source, [s,e), lane, raw refs, attributes, version). Each query q represents an unresolved requirement (referent, reason, qualification, outcome).
A full-context: prompt all N units; storage O(N); input O(N) tokens for fixed-size units, standard dense attention O(T²) compute in input tokens T; implementation/cache varies. No raw frame coverage guarantee.
B flat index: inverted postings BM25 with k1=1.2,b=.75 initial baseline; IDF log(1+(N-df+.5)/(df+.5)); dense cosine q·v/(||q||||v||), exact O(Nd) scan/storage O(Nd), sparse cost sum postings for query terms. ANN optional only after measured latency. 
C hierarchical: L1/L2/L3 parallel indexes, coarse-to-fine expansion with separate raw retrieval rescue. Storage O((N+parents)d); tree traversal O(visited) plus scoring; summaries can erase rare facts. Compare direct vs coarse-first vs parallel.
D temporal graph: G=(V,E) with verified/uncertain typed edges; personalized PageRank p=(1-a)s+a P^T p, a=.85 initial. Sparse iteration O(iterations*(V+E)); retrieval scores not probability of correctness. Directional dependencies distinct from undirected traversal; no automatic causal label. Graph assembly after entity extraction can dominate cost.
E agentic: choose evidence action a maximizing expected reduction of unresolved requirements divided by cost, subject to global + candidate budget. Cannot assume calibrated entropy; use structured status known/unknown/conflict/outside_source. Stop when closed, no novel evidence, budget depleted, or outside-source; final verification reserved. O(R*retrieval+R*LLM calls).
F hybrid: union rank lists via RRF score sum 1/(60+rank), optionally rerank top-m (m cross encoder passes); MMR lambda rel-(1-lambda) max similarity to selected. Temporal prior only when requirement justifies it; otherwise no hard recency filter. Entity match uncertain, speaker scoped. Preserve diverse competing hypotheses. Keep source clock. 
Cost objective: minimize construction+sum investigation+verification under essential dependency recall floor and false closure ceiling; report Pareto curve, not arbitrary weighted aggregate. Training-free doesn't mean free. 
Context ablation: compare blinded candidate-only/full/removed/restored/equal-length irrelevant controls. Logit KL under fixed prefix only if exposed; API outputs are structured-answer disagreement not KL. Support sensitivity not causal truth. KR01 F017–F019 pending.
