# ChompMemory — PROPOSED architectures
A: minimal sidecar using global BM25 + optional dense exact search over L0/1, temporal neighbor expansion, bounded agent tool; cheapest first test, cannot reliably bridge paraphrase or unseen modality.
B: independent L1/L2/L3 hierarchy, parallel raw and summary search, exact evidence hydration, speaker/entity filters; summaries never exclusively gate lower units. Test construction overhead.
C: typed temporal/event graph with PPR or bounded path expansion over explicit dependencies and uncertain entity links; optional cross-lane edges only on grounded support; needs KR03 labels and graph ablation.
Recommended experimentation order A -> B -> C only if matched-budget gains; D hybrid combines independent lanes and bounded agent investigation, not approved architecture. Candidate discovery remains separate; zero-to-three output no quota. 
Proposed immutable observation records reuse chomp-research-evidence/1 where feasible. Source-scoped occurrence ID, source_id/duration, half-open integer ms, lane, transcript/version fingerprint, raw evidence refs, modality state (available/absent/not_inspected/error), provider/creation provenance. L2/3 memory record has segment_ids, member_spans, neutral description, parent/children, speaker/entity hypotheses, relation_refs, confidence/verification, supersedes. Same text repeated at different time is distinct. Unknown fields null. No autogenerated authoritative transcript/quote.
Retrieval request: request_id, candidate_id, requirement_id, reason, query, direction (past/future/both), target lanes, interval constraints optional, K/token/frame/call budget. Response: searched indexes and versions, inspected spans, candidate evidence IDs, scores and scoring method, raw refs, coverage, errors, unresolved requirements, budget ledger, status. Separate interpretation evidence from viewer-required spans; do not pass noncontiguous context blindly to containing_span. 
Investigation state: known evidence, alternative interpretations, missing requirements, visited query+scope, seen occurrence IDs, remaining per-candidate and shared budgets, contradictory evidence, closure status. Deterministic executor validates source/range/provenance and retrieves, agent plans semantic query not arbitrary timestamps; stop with closed/unknown/outside_source/no_new_evidence/budget_exhausted, reserve final verifier. A complete candidate can bypass extra search only after explicit requirement check. Evidence from full completed recording allowed but restrict future in live evaluation. All queries operate within authorized recording and coverage; no external assumptions. 
Context ablation: candidate-only -> full -> remove essential group -> restore, equal-length unrelated control; blind independent judges assess meaning, referent, stance and payoff. KL only for accessible logits with common prefix, not black-box comparison. No automatic causal conclusion. 
Integration gates: coordinate source ID adapter with KR01/Keystone, dependency labels KR03, candidate interface KR04/KR06, viewer closure KR05, rights KR07, independent annotation KR08. No production edits.
