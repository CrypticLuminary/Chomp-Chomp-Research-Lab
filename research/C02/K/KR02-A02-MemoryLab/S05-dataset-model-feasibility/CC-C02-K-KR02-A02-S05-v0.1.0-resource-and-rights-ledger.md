# Initial feasibility and rights ledger
No large downloads, paid jobs or media copied. Access/license not inferred from code license. All dataset splits, temporal precision, leakage, exact commercial grants and hardware measurements pending unless specified.
- Ego4D NLQ/VQ/MQ https://ego4d-data.org/docs/benchmarks/episodic-memory/ (temporal localization / visual object tracking / moment detection; first-person; NLQ clips ~8min per pinned code README). Gated access/terms to check; code MIT only.
- QMSum https://aclanthology.org/2021.naacl-main.472/ query-conditioned meeting locate/summarize; transcript/discourse, not clip preference. AMI annotation https://groups.inf.ed.ac.uk/ami/corpus/annotation.shtml and Molweni are next sources; rights open.
- LongVideoBench https://arxiv.org/abs/2407.15754 3,763 videos, subtitles, up to one hour, video-language QA.
- Video-MME https://video-mme.github.io/home_page.html 900 videos, 254h, 2700 QA pairs, 11s–1h, audio/subtitles. Accuracy not retrieval recall.
- HourVideo https://hourvideo.stanford.edu/ 500 Ego4D videos, 20–120 min, 12,976 five-way MCQs. No independent dependency gold.
- LVBench https://arxiv.org/abs/2406.08035 extreme long video QA, exact sizes/access pending. MLVU/EgoSchema next.
- MovieChat-1K https://arxiv.org/abs/2404.17176 reported 1k videos / 2k temporal labels / 14k annotations; dataset rights open.
- MAGIC-Video release artifacts https://huggingface.co/datasets/jiazhengli7/magic-video-artifacts; availability documented by README, actual download/checksum/licenses open. Authors use EgoLifeQA, Ego-R1, MM-Lifelong; 76.4h captioned in Month experiment. No source media obtained.
