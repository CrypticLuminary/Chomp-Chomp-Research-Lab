1. RAPTOR, https://github.com/parthsarthi03/raptor/tree/7da1d48a7e1d7dec61a63c9d9aae84e2dfaa5767. raptor/cluster_tree_builder.py L55–151 constructs clustered parents, summarizes cluster text, attaches child indices, repeats until layer cap or dimension-based stop. TreeRetriever in raptor/tree_retriever.py L158–251 has collapsed all-node ranking, top_k and token cap; breaks on first oversize node instead of trying smaller later nodes; alternate top-down traversal uses selected children. Embedding/summarization models imported in tree_builder.py; exact API costs unresolved. Transfer parallel raw and hierarchy indexes, preserve timestamps and source IDs. LICENSE path 404; check actual repository metadata/rights before reuse.
2. HippoRAG current code is HippoRAG 2, not identical to 2024 paper. https://github.com/OSU-NLP-Group/HippoRAG/blob/d5c8329422e0a0b834a15874545cb6a74b4f9b26/src/hipporag/HippoRAG.py#L499-L594: preprocess chunks, embed text, OpenIE, entity/fact embeddings, fact/passages/synonym edges. Repeated identical chunk content shares ID and warns about replacing differing metadata — a hazard for same words at separate times; Chomp must preserve occurrence IDs. L704–795: fact scoring and rerank, no retained facts -> dense passage fallback, else graph search; result metadata, optional recall evaluation. Source-aware edge schema guards against mixed old state. MIT LICENSE fetched. Costs of extraction/embedding and graph link evaluation open. Adapt fallback and provenance, compare graph only after baseline.

Context records returned alongside text; invalid proportion sum rejected. MIT LICENSE fetched. Transfer separate budget and raw evidence roster, avoid mandatory expensive community summaries.
4. VideoAgent (Wang et al.), https://github.com/unique-chan/VideoAgent2/blob/52ff8f0237a02f3ed2a8e449962745f15277cc67/main.py L1–300 (first portion): parse_json, confidence and answer parsing, API cache, generate_description_step proposes target frame descriptions within gaps, self_eval requests ordinal confidence. Cache miss path calls input() before hosted GPT request, unsuitable unattended as-is. Out-of-range parsed answer/confidence falls back to random values; invalid format returns -1 or 1. Reject random fallback for Chomp. README gives EgoSchema evaluation, external cached data, MIT badge; LICENSE path 404 (not verified exact grant). Frame retrieval uses imported frame_retrieval_seg_ego; implementation and exact checkpoints remain open. Transfer iterative frame-request strategy, not confidence heuristic or forced multiple-choice answer.
