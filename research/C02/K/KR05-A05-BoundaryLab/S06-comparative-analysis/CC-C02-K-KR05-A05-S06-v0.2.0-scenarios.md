# Comparative scenarios (conceptual)
Motivation: retrieve earlier failure narrative; controversy: later qualification hard gate; roasting: claim+response; callback: distant viewer-needed antecedent may require abstention; quiet emotion: preserve buildup despite low energy; silent comedy: independent visual setup/action/reaction; gameplay: action state sequence; nested: compare shorter self-contained lesson with longer arc; interleaving: track independent streams; delayed correction: bidirectional retrieval and abstain if budget; ambiguous reference: coreference and reviewer context; infeasible: explicit no clip; multiple valid cuts: paired alternatives, not independent edge range; snap conflict: avoid shortening required span. E001 covers these 14 patterns plus simple control, using synthetic labels only. Matched source/interest core, duration cap 30s; oracle methods get supplied dependencies, so not a fair end-to-end benchmark. Fixed, coarse unit, hull, oracle constrained, dropped dependency, ignored pair conditions. Production Director and ClipSense not executed; no empirical ranking against them. Learned models not run. Compare on identical authorized sources, same discovery proposals, access, retrieval budget, call budget, render config; record wall time, cost, failures and reviewer quality.
