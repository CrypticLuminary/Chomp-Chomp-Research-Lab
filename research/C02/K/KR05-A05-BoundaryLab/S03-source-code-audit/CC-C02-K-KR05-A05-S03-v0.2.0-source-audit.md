## CALF detailed reconstruction (SoccerNet-v2 PyTorch port)
Dataset defaults ResNET_PCA512.npy and Labels-v2.json; K_V2 times frame rate; oneHotToShifts produces relative labels (dataset.py L20-L98). Model input defaults 512-D, chunk 240, 2 fps, receptive field 80; these are constructor defaults, not necessarily training config. Temporal convolution and capsules generate segmentation score sqrt(4/d * sum((z-0.5)^2)); inverse score concatenated with capsules, pooling and convolution predict spotting detections (model.py L15-L28,L136-L191). Source: https://github.com/SoccerNet/sn-spotting/blob/9842826f94e1419580a9d17219c11aca7225f7ce/Benchmarks/CALF/src/model.py#L136-L191; https://github.com/SoccerNet/sn-spotting/blob/9842826f94e1419580a9d17219c11aca7225f7ce/Benchmarks/CALF/src/dataset.py#L20-L98.
Let p denote original prediction; q=1-p, m=.9, h=.1, d relative event shift, K0<K1<0<K2<K3. Positive part [x]+. For d<K0 or d>=K3: [log(m/q)]+. K0<=d<K1: [log(m/(q+(1-q)*(d-K0)/(K1-K0)))]+. K1<=d<0: zero. 0<=d<K2: [log((1-h)/(1-q+q*d/K2))]+. K2<=d<K3: [log(m/(q+(1-q)*(d-K3)/(K2-K3)))]+. Sum all class/time entries. Spotting loss L72-L75: object coordinate squared error weighted lambda_coord + object confidence squared error + no-object confidence squared error weighted lambda_noobj + class squared error for objects; greedy matching L78-L129. The positive region after event is a spotting convention, not a gold payoff. Evaluation tolerance per SoccerNet task https://www.soccer-net.org/tasks/action-spotting; interval closure not measured. Full training/evaluation caller and original Keras comparison pending.

## TimeRefine
v9 uses cached autoregressive generation capped at 300 tokens, timestep schedule, quantized endpoint/velocity tokens. Estimated terminal endpoint = (endpoint + t*velocity)/100; intermediate endpoint = (endpoint+.2*velocity)/100. Only lower start clamp and token max 99 observed; no final ordered-range validation in that function. Empty arrays risk indexing on first/last. Need parser probes and evaluation caller trace. README link removed; do not claim checkpoint usable. Model uses CUDA in audited code. No evidence retrieval in loop.
