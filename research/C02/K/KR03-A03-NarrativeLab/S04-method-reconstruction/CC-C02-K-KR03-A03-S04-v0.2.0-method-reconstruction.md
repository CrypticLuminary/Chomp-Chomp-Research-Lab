# PROPOSED methods, not claims of trained performance
Let n occurrence units with d-dimensional features, K retrieval cap, C candidate anchors, R relation labels, B model calls. Use source-clock half-open intervals and separate identity, semantic relation, necessity.
| Architecture | objective / inference | scaling / failure |
|---|---|---|
| Pair classifier | sigmoid W phi(i,j), multilabel BCE, negative samples; score retrieved pairs then threshold dev-calibrated | O(n²dR) exhaustive or O(nKdR) sparse; label imbalance, misses non-pair support |
| Discourse parser | maximize sum log p(parent,rel|turns) subject to allowed graph; decode local arcs or structured search | O(n²) arcs; trees lose cross-thread relations; supervise SDRT |
| Latent graph | learned similarity score, top-K, h'=aggregate(W h); TP loss or relation loss | dense construction O(n²d); approximate index before scoring; opaque links |
| Typed KG | labeled occurrence graph, constraints on identity and time; retrieve bounded BFS paths | O(V+E) traversal worst, branch explosion; uncertain edges not transitive by default |
| LLM extraction | constrained schema generation + citation validity; supervised token NLL optional | cost provider-dependent; plausible hallucinations, malformed structure |
| Retrieval-assisted | union lexical/dense/entity/local/future/visual; verify each hypothesis with raw evidence | O(C*K*verify), plus index build/search; missed candidates ceiling |
| Ablation | D(G)=q(full)-q(full without G), restore and unrelated control; optional shared-prefix KL | O(B) variants; exact subsets 2^K, length effects |
| Hybrid | retrieve -> classify -> verify -> group ablate -> unresolved/closed | bounded C,K,B; compare simpler baselines, no mandatory graph |
Pseudocode: for candidate: propose missing questions; search independent lanes past+future, dedup occurrence IDs; verify typed hypothesis against supporting and contrary evidence; expand at most depth 2 if missing; test singleton and predeclared groups under budget; emit alternatives and unknowns; independently check viewer interpretation; stop budget or closure. No production calls.
Cost estimates assuming 1 atomic unit every 5s, directed pairs n(n-1): 1h n720 -> 517680, 4h n2880 -> 8291520, 8h n5760 -> 33171840. K=12 outgoing gives <=8640/34560/69120; C=20 gives <=240 candidate edges after index retrieval. Index search may still be exact O(nd) per query; cost estimate not wall-clock measured. Exclude self pairs and deduplicate. Confidence calibrated per type on creator-disjoint dev/test with reliability bins, Brier/ECE plus abstention risk-coverage; unknown is not negative. Group support as monotone OR-of-AND alternatives only when appropriate; contradiction/correction can be nonmonotone, so evaluate order and evidence compatibility. Minimal deletion sets hit every sufficient alternative; exact enumeration exponential, limit by K and target group hypotheses. KL(full||removed) measures token distribution sensitivity on identical prefix, no causal inference. API-only compare fixed semantic fields via independent judge, never call KL.
