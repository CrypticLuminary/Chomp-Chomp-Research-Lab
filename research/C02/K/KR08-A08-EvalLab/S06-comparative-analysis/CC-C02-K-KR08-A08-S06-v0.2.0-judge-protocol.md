# Human vs automatic evaluation
ADOPT deterministic checks: schema, hashes, source bounds, exact evidence ID coverage, paired regions, candidate counts, dedupe, decode/technical measurements. ADAPT AI judges for triage, question extraction, paraphrase mapping, possible contradictions, low-risk preference estimation only after calibration. REJECT sole self-judge or using model reasons as human gold. Multimodal judge gets actual rendered audio/video and verified source context for faithfulness; transcript-only cannot score visual or prosody. 
Calibration: stratified dev set of ~40–60 clip variants and 24–36 blinded pairs, balanced hard cases, negative clips, same-content boundaries and different styles. Two independent humans, adjudicator for hard gates. Compare >=2 judge families if available, no paid runs without authorization. Same rubric, anonymized labels, both orders, repeated calls on subset, frozen prompt/model, hide system output rationales and ranks. Report confusion matrices, sensitivity to serious distortion, specificity, false accept rate, selective coverage, κ/alpha, human-human baseline, tie/error rates, swap disagreement, same-model vs cross-model bias, length-conditioned performance and uncertainty. Use source evidence as judge-only input; selection models cannot see gold or judges' reasons. For conflicting order, judge disagreement, low confidence or high-risk issue, route to human. Even unanimous judges audited on random accepted sample, all potentially serious distortions escalated. No judge-only production approval; cost includes judge calls and human overrides. Pilot calibrates whether any automation worthwhile; no predeclared statistically justified accuracy threshold.
