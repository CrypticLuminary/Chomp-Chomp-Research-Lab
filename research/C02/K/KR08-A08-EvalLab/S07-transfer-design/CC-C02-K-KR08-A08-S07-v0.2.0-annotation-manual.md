# Independent human annotation manual
Goal: worthwhile, truthful and comprehensible short-form clips, not viral prediction. Source is authorized, private and frozen. Use integer source-clock half-open intervals. Do not show model proposals, scores, titles or rationales during first pass. No forced highlight or predefined category whitelist. 
## Pass A: source discovery
Rater A and B independently watch full source, with audio/visual, log reviewed intervals and missing modalities. Flag any event that may matter to a reasonable intended audience, including quiet insight, humor, informational discovery, gameplay, reaction, conflict, surprise, silent action. Write plain description of why someone would care and decisive core. Mark uncertain, do not force; include unknown/unclassifiable tags. Separate topic chapters, atomic complete thoughts/actions, speaker identity if observable, and event identity (same payoff variants share one ID). Note difficult ASR and inaccessible content. Watch pauses around source context, not only transcript; no source complete until coverage verified. For each event, note interpretation-only context vs viewer-required context. Mark essential spans with evidence IDs, relation type and direction, alternative groups, qualification triggers, unknown context and valid paired boundaries. Record negative intervals independently (not simply unannotated time). 
## Pass B: adjudication and pool
Align events by core and meaning, not timestamps alone; preserve both original annotations. Third reviewer resolves hard conflicts with evidence and reason; disputed remains disputed if unresolved. Freeze independent gold, hash, then review pooled blinded proposals and randomly selected negative intervals. Any genuinely new event goes to an independent versioned supplement; original recall fixed for primary run, supplement sensitivity reported; subsequent benchmark version frozen before further tuning. Never treat unjudged pool item as false. Gold completeness means documented coverage and protocol, not objective exhaustiveness.
## Pass C: clip-only then source comparison
Randomize clips and pairs, anonymize system; common renderer/settings and same audience brief. First watch standalone without lead-in; write who/what/why and expected implication, score opening, pacing, ending, value. Lock this response. Then watch full required source context (can be distant; do not restrict to ±10s), compare attribution, stance, qualifier, sarcasm, chronology and audiovisual evidence. Check hook/captions for misrepresentation and critical technical defects. Do not let entertainment override gates.
Hard gates: authorized source/export, faithful meaning and attribution (no serious distortion), understandable standalone for audience, essential setup/qualification/payoff where needed, technical usability (decode, intelligible audio when required, visible essential visual, no meaning-changing captions/cut). Gate pass/fail/uncertain/n/a; n/a allowed only with reason and truly irrelevant modality; uncertain hard gate → pending human adjudication, not accepted. Reject unresolved serious ambiguity, not every nuanced disagreement. Technical minor aesthetic issue can be ranking, critical defect fail. 
Ordinal 1–5 anchors: 1 poor/no value; 2 weak/awkward; 3 adequate; 4 strong; 5 exceptional. Rate independent dimensions: interestingness (would choose to watch/share to intended audience), informational and emotional value separately, setup/payoff (coherent development), opening (quickly orient without deceptive hook), pacing (no dispensable stretch), ending (resolved or intentionally natural), technical quality (clarity/presentation). 3 means sufficient, not automatically approved; overall good requires all applicable hard gates pass AND reviewer judges worthwhile. No averaging hard gates. Unknown/null allowed; record rationale, evidence, review time. Diversity is slate-level: count distinct events and redundant viewpoint/payoff; category variety optional, not forced.
Pairwise: both clips first standalone, then source if assessing overall; randomized order, independent two reviewers, outcomes left/right/tie/both_bad/unjudgeable; compare only same campaign. Same event variants especially useful for boundary, different event variants for interest; use slate pair for end-to-end. If one hard-fails, cannot win approval despite appeal. Record audience profile without personal data. Inter-rater raw agreement, nominal kappa/alpha, ordinal alpha, boundary match, adjudication count and class prevalence; if critical label reliability poor, revise rubric on dev and repeat independently, preserve old version. Never adjudicate by averaging an incorrect and correct fact.
## Worked examples (invented, not actual ratings)
A: [0,10s] "I liked the game" then [9.9,10s] "before the update" qualification. Clip [0,9.9) tIoU=.99 but changes scope → faithfulness fail even if interestingness 5. A clip may instead include a later explicit restatement if independently sufficient; annotate alternate group, not required union.
B: quiet explanation at 20–40s answers a challenge from 8 min earlier. Earlier mention may be needed only to understand the creator's intent; later local restatement can make standalone clip complete. Distinguish interpretation vs viewer evidence. A nearby unrelated mention of same game is negative relation.
C: correct result for a VOD independently confirmed no worthwhile events is zero selections with full coverage. Timeout also produces zero, but is processing_failure, not correct abstention.
D: two funny clips from same payoff, one slightly extended → same event, duplicate. Separate genuinely distinct insight even within same topic can count separately.
E: one reviewer finds dry joke compelling; other does not. Both may agree faithful. Keep pair/taste disagreement, adjudicate factual/context conflict only; do not erase audience variability.
