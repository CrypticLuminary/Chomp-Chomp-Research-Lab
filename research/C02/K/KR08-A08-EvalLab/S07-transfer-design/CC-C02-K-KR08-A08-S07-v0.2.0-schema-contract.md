# Additive sidecar contract
Keep production chomp-source-events/1 and chomp-candidates/1 unchanged. Proposed chompbench-research/0.2 sidecar is linked by source_id, duration_ms, SHA256 source bytes and legacy events file hash (null when no faithful projection), immutable rubric/hash/split. Project into legacy only when a single necessary contiguous hull and independent admissible endpoint ranges honestly represent gold; otherwise mark unavailable for legacy temporal semantics. Do not widen mandatory union or create false acceptable pairs. Native ClipLedger good/bad/uncertain and dimensions map into review records with missing values null. Separate private model-input packet from hidden scorer packet: model receives source/allowed evidence index and campaign only, no source_label, events, needs, gold hashes content, reviews, preferences, negatives, adjudication or oracle fields. Run logs may be merged only by scorer after inference. 
JSON Schema enforces shapes; Work must enforce cross-record checks: integer half-open media spans, point edge ranges allowed, max source duration, unique IDs scoped by source and type, no dangling evidence/parent/need refs, DAG parents and hierarchy containment (chapter/atomic may overlap across lanes but declare), event core present, evidence modality observable, no self-edge unless documented, recoverable needs have >=1 nonempty alternative, conditions valid nonempty triggers when conditional, duration min<=preferred<=max, paired region actually feasible, unknown/unsupported evidence not verified, no AI complete source, negative source requires fully independently reviewed coverage and no positive/disputed events, no reviewer duplicates by target/stage, adjudication references raw reviews with distinct rater IDs, pair IDs/render digests valid, final outputs max 3, ranks unique, proposals exist, artifact hash required if rendered, cap/actual units and failure status consistent, source/gold hash matches private manifest; creator aliases and media duplicates checked across splits. Annotation freeze via canonical JSON byte SHA256 manifest outside sidecar, scorer asserts expected hash and exact expected run roster. Run gold_sha256 is scorer-only bookkeeping, not prompt input. Do not trust model claimed event IDs; independent matching is authoritative. Consent record references are private opaque IDs. 
Schema is a proposed structural draft, not yet exercised against production; no human data generated. Need future explicit annotation export adapters, private split and roster manifest, cost receipt cross-validation, schema unit/mutation tests. Conditional predicates deliberately simple: trigger in interval by full evidence containment; partial trigger exposure escalated to human or fail if needed; no inference of semantic truth from interval alone. Separate rendered clip quality from source-only inference.
