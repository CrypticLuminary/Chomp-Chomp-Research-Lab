# Metric contract v0.2 (proposed)
Half-open [s,e) integer ms; 0<=s<e<=duration. Reject malformed intervals, duplicate IDs, extra source IDs; materialize missing expected results as failure with reason, never silently drop. Freeze roster, source hash, metric version, config, gold hash. Every rate emits numerator, denominator, value or null, reason, coverage, origin and unit. No mean of nulls without count. Keep representative and challenge strata separate.
## Discovery
For core c and proposal p, cover=|c∩p|/|c|; legacy proposal recall=Σ_e 1[max_p cover>=0.8]/|E| when complete positive gold; threshold is legacy convention, not truth. Also show sensitivity 0.5/0.8/1.0. At fixed candidate K and max proposal union seconds, event recall is many-to-one coverage; ranked detection AP uses stable score/id tie break and locks a ground-truth event after its first match. AP=Σ_k P(k)*TP(k)/|E|. FP includes duplicate event predictions. Maximum-cardinality bipartite matching then overlap tie-break for distinct yield; semantic event identity adjudicated for multi-core candidates; do not conflate detection and coverage. Temporal IoU=intersection/(lenA+lenB-intersection); no invalid zero lengths. Segmentation: one-to-one boundary match at frozen tolerances (1/3/5s diagnostic), P/R/F1; unit purity=Σ_pred max_ref overlap/total predicted covered duration, completeness reverse; report full partition coverage, gaps, overlap, length distribution, count error, human complete-thought rating. Coarse chapter and atomic unit scores separately; require semantic useful downstream gains, not more boundaries.
## Selection and preference
S=all final outputs including failed renders, G=independently approved, U=uncertain/unreviewed. Approval lower bound G/S; upper (G+U)/S; determinate rate G/(S-U) diagnostic. Zero output precision null. Legacy P@min(3,N) retained. Primary yield: number of distinct approved gold events per assigned VOD (0 on failure), plus independently approved new events reported separate until versioned blind adjudication; maximum 3 per VOD. Distinct event recall = one-to-one approved matches / complete positive gold. Duplicate rate=number of redundant selections / all selections, semantic identity and reason recorded; overlap proxy separate. Report rejected, uncertain, unrendered, unmatched. Pair preference W/L/T/both_bad/unjudgeable with full denominator; conditional preference=(W+0.5*T)/(W+L+T); both_bad reported and excluded from conditional preference, never credit as success. Report paired VOD-level quality/yield plus optional slate choice A/B/tie/both bad. Ordinal 1–5 histograms and medians per dimension, means supplementary. Brier=mean((p-y)^2) for determinate binary labels; reliability plots and expected calibration error only with frozen bins and sufficient n. No scalar averaging across hard gates.
## Retrieval and relation
Case = candidate, initial observed IDs, hidden missing-information needs with acceptable alternative evidence sets (DNF), recoverability status. Need identification precision/recall/F1 against semantic need IDs (human mapping; paraphrases accepted). No gold queries in autonomous arm. Query quality: independent rubric 0 irrelevant, 1 related, 2 resolves specific need; first query and cumulative evidence recall; no lexical equality. Set recall= max_g |R∩g|/|g| for each need; closure=1 if exists g subset R, require all needs resolved; retrieval precision=|unique fetched relevant IDs|/|unique fetched IDs|, repeated fetch cost separately; extra fetched seconds, tokens and IDs outside union of acceptable evidence; overlap duration union to avoid double counting. Count contradictions, qualifications, referents, callbacks separately, with evidence-grounded answer accuracy and unsupported citation rate. No evidence required → recall null, report unnecessary fetch and stopping accuracy. Unrecoverable → correct calibrated abstention; unknown recoverability not negative. Correct stop: sufficient evidence + faithful conclusion or explicitly unrecoverable with authorized coverage exhausted; early stop/oversearch/budget exhausted distinct. Report first success calls and time, never gold-assisted. 
Narrative relations: typed directed edges (u,v,type), node match first, micro/macro F1 across edge types incl no-link negatives, oracle-node and detected-node arms. Multi-label edges allowed; unknown not negative. Hard negatives same entity/time nearby unrelated; distant callback positives; direction reversals; sarcasm ambiguity and alternative interpretations. Group intervention: compare blind judges on anchor-only, full, removal of singleton, removal of minimal hitting set across sufficient groups, restoration, irrelevant equal-length placebo; necessity only if interpretation/faithfulness declines reliably and restoration repairs, sufficient groups not assumed exhaustive. Removal can create artifacts; matched edit controls and counterbalanced raters.
## Boundary
For event e, mandatory core, mandatory spans M and per-need alternative groups G, temporal closure=all M contained AND each need has a fully contained sufficient group; separately require audio/visual presence and condition predicates based on selected interval (if includes claim, require qualification). Pair acceptance = exists jointly accepted start/end region with duration limits; check pair not independent marginal ranges. Duration min/max hard campaign, preferred soft; excess context = judge-labeled unnecessary union duration/clip duration (not all unannotated seconds). Report shortest accepted duration vs actual, opening/ending ratings, midword/cut and audio/video fidelity, max tIoU over acceptable reference intervals as diagnostic. Recheck after snapping/render. Human interval-specific faithfulness is independent hard gate, not inferred by closure.
## Abstention
Expected roster: positive/negative/uncertain source gold plus system status complete, partial, processing_failure, budget_exhausted, unresolved_context, missing_run. Strict correct negative rate = count(successful full required-modality coverage AND zero outputs)/all confirmed negative assigned sources. Also conditional rate among fully processed negatives, coverage and failures; positive missed rate including all failed assigned positives. Return reasons (no worth, unresolved, incomplete, failure, budget) not inferred from empty list. Unknown gold sources excluded only from truth rate, counted in unknown and total roster.
## Human reliability and uncertainty
Cohen kappa=(p_o-p_e)/(1-p_e) for two aligned raters, p_e=sum marginal products; nominal/ordinal Krippendorff alpha=1-D_o/D_e with coincidence matrix and appropriate ordinal distance, missing ratings omitted pairwise only where >=2 ratings, not zero; D_e=0 null. Report class prevalence, raw agreement, disagreement matrix, CI by source/creator, adjudication rate; boundary agreement tolerance and interval overlap separate from categorical alpha. Bradley–Terry P(A>B)=exp(theta_A)/(exp(theta_A)+exp(theta_B)); fit connected comparisons with identifiable reference and regularization; tie-aware Davidson or explicit tie outcome; do not treat both bad as tie preference. Pilot W/L/T and raw counts primary. No universal alpha cutoff; revise rubric if critical labels disagree. Bootstrap paired differences by creator (then sources if multi-level), not clips; few creators yields unstable CI; exact sign/permutation sensitivity and raw per-creator results, no statistical guarantee. Pre-register primary metric and guards; multiplicity control or exploratory secondary labels.
## Cost
Per assigned source, cold end-to-end wall seconds, CPU/GPU seconds/peak measured RAM/VRAM, actual tokens in/out, embeddings, unique/repeated retrieval, frame count and resolution, source union coverage per modality, candidate count and union duration, all sent/retried/failed/cache calls, rendering, human time, actual invoice cost or null. Separate cache replay and amortized index cost (C_build/N+C_query) from cold cost; subscription cost unknown, not zero. Quality/cost curve at fixed caps and actual consumption; cost per approved distinct clip null if yield=0, report totals and failures. Budget matching requires known equal relevant caps, same source and availability; actual consumption need not equal, report actual. Compare Pareto frontiers without extrapolating.
