# Authorized dataset and effort
Pilot 4 complete VODs (~90 min each), 3–4 creators, with 2–3 dev and at least 1 creator-disjoint locked smoke holdout. This tiny holdout diagnoses pipeline problems, not population significance. Sample authorized random VODs from a defined creator/category roster using fixed seed before labels; supplement targeted challenge examples separately (quiet discussion, payoff, sarcasm, silent gameplay, distant callback, no-interest, ambiguity, ASR failure). Genuine negatives discovered by independent source inspection, not fabricated; enrich separate negative set if random draws have none. Negative intervals sample stratified by modality/activity before model outputs and confirm by humans. Keep source private and local; public repo contains schema, synthetic fixtures and non-sensitive hashes only if permission allows. No paid API/GPU or gated dataset copying.
Two reviewers view independently at <=1.25x when comprehension retained; normal speed for prosody/action. Pilot workload estimate: 6 source hours x2/1.25=9.6 playback h; pause/log +6–10 h; 40–60 unique event or candidate variants x2 x4 min =5.3–8 h; 24–36 pairs x2 x3 min=2.4–3.6 h; adjudication 3–5 h; setup/QA 2–4 h. ~28–40 reviewer-hours total (rounded; planning estimates, not measured). At hypothetical $5/h $140–200; $10/h $280–400; volunteer cash outlay may be zero but labor not zero. 
Expanded 12 complete VODs x90 min=18 source h, 6–8 creators, 4–5 development creators, 2–3 held-out creators; at least one complete negative if available, all negative sources kept. Same effort scales to ~80–120 reviewer-hours, $400–600 at $5/h or $800–1200 at $10/h. Existing validator target 24 sources remains unchanged; 12 is intermediate, not complete_dataset. Collect actual stopwatch logging and update forecast. 
Lock split, private canonical manifest, annotations, reviewer IDs/pseudonyms, rubric and prompt hash before tuning; dev results accessible to engineers, holdout gold accessible only scorer/Nexus. Near-duplicate source hashes and creator aliases manually verify, don't split same recording/creator. Do not tune on test misses; create new version and untouched holdout. Later training size via creator-disjoint learning curves at 25/50/100% dev, repeated seeds; choose smallest stable plateau; no training authorized now. 
Public external data: Rhapsody gated; no media/model redistribution. QVHighlights and LongVideoBench distinct data/code terms; check each before use. Personal research doesn't erase redistribution rules. Dataset access/weight/runtime feasibility unresolved; no claims of model licensing approval.
