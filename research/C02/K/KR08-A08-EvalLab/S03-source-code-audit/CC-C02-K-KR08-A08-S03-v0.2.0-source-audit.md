## Follow-up source audit
- [QVHighlights pinned eval.py](https://github.com/jayleicn/moment_detr/blob/b7e553ac3b0c898ee6b85e03ee507c064eab89ca/standalone_eval/eval.py#L19-L95) builds data_triples from pred_qid2data (only populated by predicted windows), so a submitted query with an empty window list can be excluded from moment AP even if outer qid set matches; R@1 indexes first prediction and can raise. This can reward malformed responses by chance; Chomp must log invalid output/failure and not guess. evaluate_longvideobench counts exact option correctness over supplied rows; full harness roster not audited. Aggregator adds each result to duration and question-category buckets, then sums bucket sizes as Overall num. If each sample belongs to two disjoint bucket sets, count is 2N but weighted accuracy remains unchanged; no evidence the reported accuracy itself is inflated. Chomp must namespace slices and compute overall directly from unique assigned roster.
