# Literature and transferable evidence
Accessed 2026-11-27. SOURCE denotes inspected paper/README/code, REPORTED author results, PROPOSED design. No upstream benchmark scores reproduced.
- [Rhapsody COLM 2025](https://proceedings.colm.cc/paper_files/paper/2025/hash/24fd58f52ff8d0496add8da3991644e9-Abstract-Conference.html): ~13K podcast episodes, replay-derived segment labels. Useful weak speech-interest supervision; replay confounded by seeking, popularity, sponsor skips, audience and exposure. Not standalone faithfulness or gaming highlight gold. Compare text, speech, combined and quiet slices; no gated raw samples redistributed.
- [QVHighlights NeurIPS 2021](https://proceedings.neurips.cc/paper_files/paper/2021/hash/62e0973455fd26eb03e91d5741a4a3bb-Abstract.html): human query, relevant windows, five-point saliency; three raters per relevant clip verified in evaluator. Query-conditioned relevance differs from open discovery. Adapt multi-rater distributions, AP, explicit query diagnostic only.
- [Chapter-Llama CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Ventura_Chapter-Llama_Efficient_Chaptering_in_Hour-Long_Videos_with_LLMs_CVPR_2025_paper.html): long video chapter partition/title; useful coarse semantic index but chapter granularity not clip readiness. Code audit S03; separate boundary and semantic coherence.
- [NEST EMNLP 2026](https://aclanthology.org/2026.emnlp-main.2512/): authors report 1005 movies, ~103 events per movie, best zero-shot ETD <8%, EL <6%, EAE <11% on main subsets. Scripted movie event ontology not livestream gold; evidence of hard grounding, not calibrated performance for Chomp. KR03-F007 reports small independent gold study, not rerun. Repository aliasgerovs/nest README returned 404; source unavailable.
- [LongVidSearch](https://arxiv.org/abs/2603.14468), [release](https://github.com/yrywill/LongVidSearch/tree/4aa5620e06ca1bc5cc7cfce2b3e3ed0a5ae82d4e): reported 3000 QA pairs, 447 long videos, 2–4 necessary hops; fixed tools and answer cost. Question given, unlike missing-context detection; add open hypothesis stage, actual evidence coverage and no-answer cases.
- [LongVideoBench](https://github.com/longvideobench/LongVideoBench): interleaved subtitles/frames, multiple-choice referring questions. README example 64-frame dataloader, 16-frame default image evaluation. MCQ can exploit answer options; test open reconstruction, not MCQ alone. Dataset README CC-BY-NC-SA 4.0, don't redistribute.
- [Pull quotes](https://aclanthology.org/2020.coling-main.6/): editor-selected sentence inclusion differs from summarization; proxy for quiet speech, not neutral truth. Source evaluation ROC AUC per article; rank/recall under 3-clip constraint required.
- [Buckley & Voorhees 2004](https://www.nist.gov/publications/retrieval-evaluation-incomplete-information): pooled relevance incompleteness motivates known-positive recall plus independent source inspection and sampled audit, not interpreting unjudged as negatives. IR collection results not video annotation proof.
- [Bradley–Terry 1952](https://doi.org/10.1093/biomet/39.3-4.324), [Chatbot Arena ICML 2024](https://proceedings.mlr.press/v235/chiang24b.html): paired preferences allow relative ranking. Small pilot not sufficient for stable global scores; report wins/losses/ties/both bad first, fit only connected preference graph, uncertainty by creator.
- [Krippendorff reliability](https://www.asc.upenn.edu/sites/default/files/2021-03/Computing%20Krippendorff%27s%20Alpha-Reliability.pdf), [Zapf et al. 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC4974794/): nominal/ordinal alpha, incomplete ratings; agreement is not validity. No universal pass threshold; report uncertainty and prevalence.
- [MT-Bench NeurIPS 2023](https://papers.nips.cc/paper_files/paper/2023/hash/91f18a1287b398d378ef22505bf41832-Abstract-Datasets_and_Benchmarks.html): position, verbosity, self-enhancement bias; >80% agreement reported in text-assistant context, not evidence for clip grading. Swap pairs, calibrate on dev, audit holdout independently. [Reliability without Validity](https://arxiv.org/abs/2606.19544) reports consistency can coexist with position bias; preprint, not independently verified.
- [QAFactEval NAACL 2022](https://aclanthology.org/2022.naacl-main.187/): QA-based factual consistency complementary to entailment; adapt source-vs-clip proposition checks, not a sole gate because pragmatics, speaker attribution and audio/video differ.
Decision: use external datasets for component probes and training only under terms; final evaluation uses independent authorized creator-disjoint VODs. Actual engagement only later external validation with exposure and confounding documented, no publication needed for pilot.
