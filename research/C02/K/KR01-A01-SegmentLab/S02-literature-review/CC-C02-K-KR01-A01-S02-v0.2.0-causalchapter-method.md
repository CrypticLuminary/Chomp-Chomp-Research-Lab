# R01 Priority 2 — CausalChapter mathematical dossier
Primary: Duan et al., EMNLP 2026 https://aclanthology.org/2026.emnlp-main.635/ ; detailed equations and tables read via arXiv v1 https://arxiv.org/abs/2609.08686 (HTML mirror). Distinguish preprint from code release. No reproduction of trained paper results.
SOURCE (paper §3.1–3.2): contiguous chapter partition; each ASR sentence u_i with times is represented by fused text and 1fps CLIP visual features z_i. Base classifier yields two class logits o_i; current segment ASR, compressed visual features, time prompt and pooled features yield initial description. Silent content outside ASR units is not guaranteed coverage.
LCDS (§3.3, eq2–3): candidate boundary after i. A_i preceding W vectors, B_i following W. MLP R_phi predicts B_hat=R(A_i); mask each preceding vector r, predict B_hat^(-r). d_i=(1/W²) sum_r sum_j [1-cos(B_hat_j,B_hat^(-r)_j)]. Compare d_i to mean d_q of nearby positions: s_i=MinMax(max(0,mean_neighborhood(d)-d_i)); add learnable gamma*s_i to boundary-class logit. Strong support drops suggest boundary, but weak model/masking saturation can cause false positives; not physical causality. Need constant-range normalization guard, edge windows, zero-vector treatment and mask distribution specified in implementation. Predictor trained reconstruction D_rec, exact implementation unresolved. O(n*(W+1)*R_cost+n*W²*d) after embedding; batching can reduce wall time. W=5 paper.
CSSE (§3.4 eq4–7): h_k embeds segment + first pass description. Candidate set union previous near and top-M earlier semantic neighbors. Generate common reference y_ref using all candidate contexts. Teacher force same y_ref prefix, compute mean tokenwise KL(p_full||p_without_j) over T reference positions. Rank by KL and use top-K for final generation. No new reference sampling per removal. Complexity per chapter reference generation + (M+1) teacher-forced variants + final generation; compact pool, no all-history rescoring. Historical contexts only in paper; future qualification retrieval is our extension. KL measures prediction sensitivity, not truth/completeness or causal necessity; irrelevant stylistic influence and redundant/joint support remain risks.
Loss (§3.5 eq8–11): supervised boundary NLL + following-window reconstruction + autoregressive description NLL conditioned on selected context + timestamp token NLL. Paper uses Qwen2.5-7B/Llama3.1-8B main, Qwen2.5-3B ablation, rank/alpha 32/64 and 8/16 for 7B and 3B, AdamW 5e-5, batch1, max input8192, W5/K5, H800 80GB.

PROPOSED transfer: for each candidate unit build a canonical factual claim/intent/stance vector and evidence-grounded structured questions. Compare full context vs clip-only and removal of single required dependency groups (not arbitrary tokens), then counterfactual restoration. Ask same questions with evidence IDs; score stance flip, qualification loss, referent ambiguity, setup/payoff loss, not mere changed wording. Include negative control unrelated equal-length context, multiple redundant contexts (group removal), paraphrase stability, order randomization, no-context abstention. Opinion: remove later 'except...' qualification, require unchanged intended stance or mark incomplete. Joke: remove setup/speaker antecedent, test resolution not laugh prediction. Motivation: remove struggle-to-lesson relation, test preserved reasoning not emotional intensity. Story: remove antecedent and outcome, test actor/action/outcome and chronology. Distinguish essential-for-understanding vs helpful context vs irrelevant, preserve noncontiguous refs; never fabricate causal edge. KR03 owns dependency semantics; KR05 decides final clip expansion or abstain. KR02 retrieves bounded past and future evidence for offline VOD. Test against independently annotated gold, not generator self-judgment. With black-box APIs no full logits: structured QA answer comparison is a surrogate, not CSSE/KL. No paid calls.
