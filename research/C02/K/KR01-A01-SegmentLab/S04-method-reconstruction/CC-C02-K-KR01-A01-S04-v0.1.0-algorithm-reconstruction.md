# Methods — mathematical reconstruction (PROPOSED unless cited)
Let ordered atoms x_i with half-open source spans [s_i,e_i), embeddings z_i in R^d and modality availability m_i; n atoms, L max segment atoms, k local window width.
| Family | Objective / pseudocode | Complexity after extraction | Training / output / failure |
|---|---|---|---|
| A fixed windows | for t=0, stride, ... emit [t,min(t+w,T)) | O(T/stride) | none; intervals; arbitrary boundaries, duplicate overlap |
| B embedding gaps | g_i=1-cos(mean(z_{i-k:i}),mean(z_{i:i+k})); smooth; choose peaks above dev threshold | O(nd) prefix sums + O(n) peaks | pretrained encoder; boundary scores; repeated vocabulary and sarcasm |
| C statistical changes | choose breaks minimizing sum segment cost + beta*break count; PELT prune under valid additive cost | worst O(n²d); conditional expected linear | none for SSE; boundary indices; gradual changes missed |
| D bounded DP | C(a,b)=sum ||z_i||²-||sum z_i||²/(b-a); F(b)=min_a(F(a)+C(a,b)+lambda); backtrack | O(nLd), O(nd+n) memory | none; flat partition; length limit, penalty sensitivity |
| E temporal clustering | initialize singleton adjacent nodes; merge adjacent minimum Ward delta = n_a*n_b/(n_a+n_b)*||mu_a-mu_b||²; stop at threshold; repeat levels | heap O(nd+n log n) with adjacent links and centroid updates O(nd) | none; hierarchy; greedy irreversible merges |
| F sequence label | p_i=sigmoid(w^T h_i); BCE against boundary labels, threshold or CRF decode | O(n) head plus encoder | supervised labels; boundaries; ambiguity and domain shift |
| G temporal transformer | h=Attention(Q,K,V); boundary head BCE; local windows/sparse attention for scale | full O(n²d) attention, local O(nkd) | pretrained/fine-tuned; visual/dialogue boundaries; GPU and domain costs |
| H LLM | prompt with ordered IDs and context; generate start/end IDs and descriptions; validate; stitch overlaps and verify seams | provider-dependent, dense attention prefill often quadratic; record tokens and calls | zero/few shot or tuning; units; hallucinated spans and inconsistent resolution |
| I multimodal | per lane gap score; preserve independent proposals; optional calibrated logistic fusion or rank fusion; no required agreement | O(sum n_l d_l + sorting) | model optional; separate tracks, missingness; uncalibrated strengths |
| J hierarchy | coarse partition from change score; refine each block plus seam halo; retain nested/crossing units and separate dependency graph | O(sum levels n_l L_l d_l)+ bounded model calls | no mandatory training; multiple resolutions; early coarse errors propagate |
TextTiling (Hearst 1997) lexical cosine valleys motivate B; PELT (Killick et al. 2012) motivates C; UBoCo (Kang 2022) uses temporal self-similarity, unlike our simple B. Above DP/SSE and hierarchy are generic proposed baselines, not exact implementations of papers.
Pseudocode: validate atoms; compute per-lane gaps; DP with min length and penalized fragmentation; construct L1/L2 and L3 with separate penalties; for each uncertain gap request at most B local model inspections; reconcile only if evidence IDs support boundaries; store alternatives instead of forced merge. Preserve gaps and unknown status. Do not require all segments to be nested in one tree. Allow a lesson nested in a story and visual action crossing a dialogue episode; use parent containment within same lane and cross-lane association edges with explicit reasons. Dedup downstream by semantic identity and core overlap, not by context overlap alone.
Uncertainty: boundary candidates can be discrete timestamps or acceptable intervals; confidence producer-specific, not calibrated probabilities. Collect multiple annotator acceptable windows. Do not widen intervals arbitrarily to improve recall; measure width and coverage. Separate physical cuts, discourse closure and downstream editorial boundaries.
