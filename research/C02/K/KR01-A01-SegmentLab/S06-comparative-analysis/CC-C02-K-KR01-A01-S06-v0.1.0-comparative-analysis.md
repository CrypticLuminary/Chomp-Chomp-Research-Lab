# Comparison and failure cases
Qualitative comparison (no arbitrary scores, no incompatible benchmark comparisons).
| Method | Granularity / grounding | Speech / visual | Hierarchy/overlap | Readiness and limitation |
|---|---|---|---|---|
| fixed | clock windows | none intrinsically | no / overlapping by stride | trivial cheap baseline; cuts thoughts |
| TextTiling | topic gap at text offsets | speech proxy / none | flat | CPU, brittle disfluency |
| embedding DP | coherent contiguous units | independent lane embeddings | repeated scale / crossing via separate lanes | proposed CPU baseline, thresholds |
| Chapter-Llama | hour-scale coarse HH:MM:SS chapters | ASR + frame captions in paper | flat | adapters listed; CUDA; CLI speech-only |
| ChunkyEdit | thematic interview chunks | transcript-first | related noncontiguous organization | human-in-loop; not automatic clip quality |
| GEBD/UBoCo | visual event boundary | no speech required | generally flat | visual lane; static talk invisible |
| STEPs | procedural step clusters | visual motion | recurring clusters | code, CUDA, rights unresolved |
| ARC-Chapter | hour-scale chapters and multiple description levels | ASR + video; modality dropout | summary hierarchy, not proven arbitrary overlap | API only verified |
| CausalChapter | sentence-aligned topic boundary and cross-chapter context | multimodal | dependencies, not arbitrary overlapping events | paper mechanism, no reproduced code |
| NEST | localized movie event graph | dialogue, audio, video | hierarchy and long-range edges | demanding benchmark, no available repo verified |
| GraphTP | scene-level turning points | screenplay + movie features | graph, assumes segmentation | scene importance not segmentation |
A quiet motivational story: speech semantics, local closure + nested lesson; visual GEBD likely misses. B controversial opinion: preserve later qualification; change score alone may cut it; verify completion. C roast: retain preceding speaker setup; KR02/KR03 links. D rapid topic switch: local gap peaks/LLM can propose close; verify last claim not truncated. E silent visual comedy: visual/action lane and independent context, not ASR gating. F simultaneous gameplay and unrelated conversation: separate overlapping tracks; global partition is lossy. G nested lesson: L2 lesson within L3 story, retain both IDs; dedup at editorial stage. H delayed callback: local segment plus earlier dependency, not huge contiguous span. I noisy transcript/missing chat: preserve missingness; acoustic/visual independently propose; no confidence penalty for absent chat. J routine footage: valid segmentation; no interest label. These are conceptual scenarios, not observed real results.
Research gaps: no cross-sector evidence establishes superiority on creator-disjoint unstructured livestreams; no model simultaneously solves arbitrary fine speech units, silent events, overlap and low-cost grounding; no full model inference here. Prioritize cheaper baselines and human evaluation.
