# Transfer design — PROPOSED, not authorized integration
D001: compare three architecture families.
A. Holistic chapter LLM: timestamped speech and sparse frame captions→coarse chapters→fine subsegment prompts. Advantage global thematic coherence; cost and seam/truncation risks, speech-guided bias.
B. Local embedding change + bounded DP: per-lane atom embeddings→local scores→partition→optional local LLM closure. Cheap, measurable, deterministic without LLM. Weak implied meaning, same-topic thought closures and sparse speech.
C. Parallel hierarchical evidence index: B for independent speech and visual lanes plus selective semantic closure and context relation retrieval; coarse topic index optional. Cross-lane association only with evidence; preserve overlapping units. Recommended test architecture, not evidence of superiority. A is useful comparator; avoid monolithic mandatory model. D002: require visual rescue sampling independent of ASR. D003: require structured evidence IDs and validation rather than naked generated timestamps.
Proposed schema chomp-segments/0-proposal: source_id, duration_ms, segment_id, lane (dialogue/visual/acoustic/social/topic), level (L0–L3), start_ms,end_ms, parent_ids,child_ids, evidence_ids, speaker_ids, description, availability map, boundary alternatives {start_ranges_ms,end_ranges_ms}, boundary_score {producer,raw,calibrated:false}, context_dependency_ids (external KR02/KR03), producer {method,model_version,config_hash}, verification_status. Example: dialogue L2 [120000,172000) overlaps gameplay visual L2 [140000,185000); no forced association. ID derived from source + lane + level + span + evidence/config identity; edits create new version and supersedes reference. Validate integers, bounds, source identity, references, DAG for containment, same-lane parent containment; cross-lane edges distinct; allow gaps for unavailable modalities. A segment is not a clip, interest score or final boundary.
Budget: cache features by source+producer; select uncertainty candidates under separate extraction/retrieval/token/latency ceilings; preserve unexplored regions; never use absence as rejection. Coarse-to-fine seam overlap, global IDs and deterministic stitching. Track failed calls separately. Validate against current TranscriptIndex and verified bundle; no replacement of existing models. KR02 indexes dependencies; KR03 defines relation types; KR04 ranks interest; KR05 closes editorial boundaries; KR06 accepts unit proposals; KR07 licenses/models; KR08 independent gold; Keystone owns integration. Nexus must review schema before adoption.
