# R01 semantic annotation contract v0.2.0 — PROPOSED
Questions Q002/Q003/Q006/Q007/Q012/Q013 (canonical register).
Unit is not a highlight, publication or final clip. Annotators see original authorized source and ASR, not system predictions. Source clock integer half-open [start_ms,end_ms); annotation clock aligned with PTS; speech boundaries map to words when available, unknown precision otherwise.
L1 atomic semantic unit: smallest interpretable discourse act or observable action that can be grounded, e.g. one claim, question, answer fragment, qualification, action onset/completion, meaningful visual state change. A clause may need earlier reference; mark dependency, don't force standalone meaning. Do not split simply at ASR chunk or speaker pause. Backchannels may be atomic but not independent complete thought.
L2 complete thought/event: a minimal coherent span or span-set accomplishing one identifiable communicative or physical objective, with its necessary setup, qualification, response or outcome accounted for. Contiguous core can be independently meaningful, context may be outside it. Record closure status complete_local, complete_with_dependencies, unresolved, interrupted, unknown; if only partial, retain hypothesis but don't label complete. Multi-speaker Q/A can be one L2. Same topic can have several L2; an extended story can contain a shorter lesson L2. Visual event L2 includes necessary state change and outcome; silent content valid.
L3 topic/episode: maximal coherent contiguous thematic or activity grouping at a chosen resolution, containing multiple L1/L2 when present. Broad subject change is evidence, not automatic cut. Same topic may recur in noncontiguous episodes; link recurrence, do not merge time across unrelated material. Do not force visual L2 under dialogue topic. Allow lane-specific L3 partition only within annotated coverage; topic lane may be sparse.
Representation: segment id, source id, lane, level, primary core [s,e), optional ordered nonoverlapping member_spans (each within envelope; gaps explicitly not included), essential_spans with role, evidence IDs (source, word, frame or observation), speaker refs/uncertainty, short neutral description, closure status, parent/child IDs, relation refs, modality availability (available/absent/not_inspected/error), boundary candidates, provenance and verification status. Nested L2 same lane allowed via contains relation even same level; crossing units can overlap without parent relation; hierarchy acyclic. Cross-lane temporal overlap alone is not semantic relation. Each contiguous span has own start/end tolerances with inclusive integer endpoint ranges; annotate multiple disjoint acceptable ranges if truly alternatives; preserve correlated start/end pairs rather than Cartesian product. Point start/end included in an accepted pair only if accepted; unknown range null, not [0,duration]. Start must be < end and end <= duration. Ranges constrained to source, no end/start reversal. Annotators independently mark ranges then adjudicate; retain per-rater originals and evidence for disagreement.
Context dependency separate relation graph (KR02/KR03): from segment requiring understanding to support segment, type e.g. setup, antecedent, qualification, correction, explanation, outcome, callback, answer-to, with direction past/future/overlap and necessity essential/helpful/uncertain. Evidence IDs and counterfactual question: what interpretation changes if support omitted? Avoid causal claim from temporal overlap. For offline VOD inspect future qualification; if future unresolved preserve status. Essential context may be noncontiguous: dependency is retrieval, not automatic edit permission. KR05 chooses contiguous final clip or abstains.
Example (synthetic): dialogue L1 claim [10000,18000), qualification [23000,30000); L2 opinion envelope [10000,30000), member spans both, closure complete_local if both included, required spans both. Nested L2 life lesson inside longer L2 story; overlapping visual game action [15000,35000) independent. Later correction [110000,118000) essential dependency; original local opinion may be complete_with_dependencies, not final publication ready. Separate L3 college topic and visual game topic. Valid routine recordings may have many L2 and no highlights.
Annotation protocol: two independent annotators for per-lane coverage and L2 closure, blinded to predictions and interest ratings; mark absence vs not inspected; adjudicate with third/consensus; track unresolved cases; separate interest judgments (KR04) from unit annotation. Report inter-rater pairwise boundary tolerance and L2 one-to-one/core+essential coverage, plus nested/crossing relation agreement. Do not score unknown regions as negatives. Do not fit annotation windows from system outputs. Benchmark frozen before dev tuning.
