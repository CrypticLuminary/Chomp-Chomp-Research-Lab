# Problem definition and taxonomy
Q001: Can semantic units recover complete thoughts and visual actions better than fixed windows at matched downstream budgets? Q002: Which resolutions must overlap? Q003: Which observable evidence can ground a boundary? Q004: How does missing speech change allocation? Q005: What is the cost of context expansion?
| Task | Input → output | Supervision | Transfer |
|---|---|---|---|
| Temporal segmentation | sequence → intervals | any | umbrella |
| Shot boundary | frames → camera cuts | labeled cuts or visual heuristics | physical L0 only |
| Speaker turn/VAD | audio → speech intervals/turns | pretrained or heuristic | L0, not thought completion |
| GEBD | visual sequence → perceived boundaries | human annotations or self-supervised | visual L1/L2 |
| Topic segmentation | utterances → contiguous topic blocks | unsupervised or labeled | L3 |
| Dialogue segmentation | turns → dialogue blocks | labels/coherence | L2/3 |
| EDU segmentation | words/prosody → clause-like units | discourse labels or rules | L1 |
| Discourse parsing | units → rhetorical relations | discourse tree labels | KR03 |
| Temporal action segmentation | frames → per-frame action labels | usually labeled actions | L1/2, closed vocabulary risk |
| Temporal action localization | sequence → action class and interval | labeled intervals | proposal, not full partition |
| Video grounding | video + query → interval | paired language and times | KR02 retrieval, query required |
| Dense video captioning | video → intervals + descriptions | supervised/pseudo labels | open event descriptions |
| Chaptering | long video → starts + titles | user chapters or pseudo labels | L3 |
| Summarization | source → compressed text/video | varied | indexing, lossy |
| Key-step discovery | procedural video → step intervals/clusters | self/weak supervision | visual L2, recurring actions |
| Narrative segmentation | evidence → story units | varied | L2/3, KR03 relations |
| Highlight discovery | video → candidate events | preference or heuristic | downstream KR06/KR04 |
Five levels: L0 physical evidence, L1 atomic clauses/actions, L2 complete discourse/event units, L3 episodes/topics, L4 typed dependencies rather than a partition. Parallel lanes can overlap; nesting may be non-strict across levels; context is not membership. A static webcam does not imply unchanged meaning. Topic shifts are not necessarily complete-thought boundaries. Segmentation may cover all ordinary content without approving a highlight. Source clock is canonical; source text is untrusted. Evidence: PROPOSED taxonomy synthesized from literature, not a trained ontology.
