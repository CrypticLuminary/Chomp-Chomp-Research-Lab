# Experimental protocol (not executed beyond parser check)
E002 baseline segmentation: compare fixed 30/60/90s, overlapping 90/60, existing 18s ASR-derived observations (not semantic partition), lexical TextTiling, embedding gap + DP, structured LLM, Chapter-Llama ASR and actual caption+ASR pipeline only if verified, hybrid hierarchical independent lanes. Freeze same authorized VODs and ASR, source clock, compute budgets and splits. Run separate extraction-inclusive and proposal-only cost reports. Match candidate budgets downstream (10/20/40 per hour) plus total inspected footage and provider tokens. Randomize/blind human reviewers; tune thresholds/prompts only dev. Proposed pilot 12–20 VODs spanning creator, genre, quiet dialogue, silent visual and routine footage; size subject to annotation resources and power analysis, not a promised adequate sample.
H1 coherence fixed vs semantic; H2 flat vs nested with identical features; H3 speech recall under equal budget; H4 independent vs global fusion on interleaved scenes; H5 acceptable boundary ranges vs point estimates measured by downstream edits and interval width; H6 adaptive vs uniform retrieval at matched quality and cost; H7 downstream recall at equal budget with identical ranker. Ablate each independently.
Gold: two independent annotators label L1/L2/L3 per lane; source-relative half-open event core, complete thought/context, permissible start/end ranges, evidence IDs/speaker certainty, dependencies, overlap and routine regions, annotation coverage/missingness. Adjudicate disagreements, retain originals, creator/source-disjoint train/dev/test, freeze test before tuning. Avoid using predictions as gold.
Metrics: maximum-cardinality one-to-one boundary matching within fixed tolerance (e.g. 1/3/5s) per lane/level, then precision=TP/pred, recall=TP/gold, F1=2PR/(P+R), null if denominator undefined; report empty cases explicitly. Pk compares same-segment membership at distance k (half mean gold segment length on equal utterance grid), WindowDiff compares counts in windows, both only flat partitions. Segment IoU=intersection/union, one-to-one matching plus separately many-to-one coverage for nested spans; report fragmentation and merge counts. Annotator ranges: hit if prediction within accepted interval, report interval width and misses. Complete-thought/event coverage requires gold essentials, judge coherence blind. Downstream candidate recall uses current ChompBench >=80% core coverage, count and context coverage; not identical to boundary F1. Runtime, peak RSS, tokens, calls, bytes, GPU seconds, actual billed cost, missing modality, failure rates. Bootstrap paired VOD-level CIs only with adequate independent sample.
