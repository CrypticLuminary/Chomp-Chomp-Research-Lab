Paper: https://arxiv.org/abs/2504.00072 ; HF https://huggingface.co/lucas-ventura/chapter-llama . Paper architecture: coarse speech-based chapter prediction → sample frames at selected positions plus coverage for no-ASR regions → visual captions → timestamped ASR+caption text → independently tuned final adapter → chapter starts/titles. Code audit confirms ASR and caption representation and adapter mapping, but full training/frame selection/combined prompt pipeline NOT fully traced. The local single-video entry point should not be described as the paper's full system. No evidence-ID grounding; generated timestamps can be wrong even if parseable. Recommended adapt evidence IDs, strict half-open bounds, no silent overwrites, explicitly distinguish one chapter from model failure and never snap to unrelated speech when no speech exists. Training configs, evaluation metric implementations, full tests and frame selector still OPEN. See parser-check scripts and results.
