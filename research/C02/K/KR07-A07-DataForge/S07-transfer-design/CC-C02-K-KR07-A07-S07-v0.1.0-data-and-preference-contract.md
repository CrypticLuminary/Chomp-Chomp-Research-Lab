# Custom data and labels
Phase 0: 100 examples across >=5 creators, include quiet dialogue, jokes requiring setup, silent visual actions, loud routine negatives, false sensational fragments, no-worthy footage. Schema validation only; do not claim generalization. Phase 1: 500–1000 candidates and independent source-level positive core annotations; creator/source group-disjoint, target 60/20/20 by creator if enough, test frozen before tuning; strata by category/length/missing modalities. Source search independent of model proposals prevents selection bias. Phase 2: 3000+ examples only if learning curves justify; prioritize model disagreements and missed gold cores; preserve random fraction. Weak Rhapsody replay data separately labeled, channel-disjoint when possible; original split retained solely for replication. Annotate overlapping windows as same event occurrence, avoid crossing splits, duplicates/near-duplicates and creator style leakage.
Per source: rights_ref, source hash, creator pseudonym, category, duration, split, analysis coverage, modality mask. Per occurrence: source_id/event_id, core [start,end), optional envelope, required spans with alternative groups, interpretation-only refs, category optional multi-label, independent ordinal interest 0/1/2/3, confidence, audience, evidence IDs, pairwise chosen/rejected/tie/abstain, approved/reject reason, boundary alternatives as correlated pairs, reviewer ID/version. Negative classes: mundane loud, unsupported sensational, incomplete joke, irrelevant nearby, same words wrong speaker, false visual, repetition, mid-sentence, omitted correction. Quiet/silent worthy are positives. Keep reviewer disagreement, adjudication, explicit unknown and provenance. No private data in public repo.
Label efficiency proposals: first binary keep/skip/uncertain and core interval; then pairwise matched-source preference and context-required spans for ambiguous cases; annotate corrected boundaries for accepted candidates; free-text reason on hard failures only. Ordinal gives graded utility but agreement lower; pairwise easier on subtle ranking but cannot calibrate absolute accept threshold without independent no-worthy negatives. Budget assumptions: binary/ordinal 60–120s/example plus context; 100=1.7–3.3 reviewer-hours per reviewer, 1000=16.7–33.3h. Pair 1–3 min each -> 500=8.3–25h per reviewer. Source annotation adds actual VOD watch time and replay; budget separately. Two independent reviewers and adjudication for holdout; disagreements not silently discarded. Active learning only training pool, keep held-out fixed. EvalLab KR08 branch had no diff at initialization, coordinate before schema change.
Distillation gate: teacher only permitted API and source rights; frozen holdout untouched; log model/prompt/version and teacher uncertainty, no self-generated gold. Compare human-only vs weak+human and teacher-only diagnostic. Separate soft targets and hard labels, calibrate on human dev, check subgroup recall, unsupported evidence, false positive zero-worthy. No self approval.
