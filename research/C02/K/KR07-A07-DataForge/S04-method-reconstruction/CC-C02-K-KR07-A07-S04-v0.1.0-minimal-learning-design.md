# Proposed minimum intelligence model
Input at 10s stride, variable 10–60s context around utterance/scene seeds. 384D sentence embedding + 16 scalar features (speaker turn, pause, relative RMS, novelty, position, modality masks). Logistic 400+1=401 parameters; 400->64->1 MLP 25,729 parameters. Optional frozen 768D HuBERT + 512D CLIP -> 1680 features (including same 16); 1680->64->1 =107,649 params. These are design counts, not proven architectures. TCN 400->64 projection 25,664; two 64->64 temporal conv k3 each 12,352; output 65; total 50,433. Mask padded windows, source boundaries, missing modalities; avoid using channel ID as feature. Bidirectional temporal context permitted for completed VOD; distinguish causal mode in future. Keep episode-relative scores vs calibrated across sources.
Train logistic BCE with class weighting or pairwise softplus(-(s_good-s_bad)); fit preprocessing/weights on train only; evaluate ordinal/pairwise independently. No forced positives for zero-worthy VODs. Compare text-only, acoustic-only, visual-only, chat-only, early fusion, late RRF, fixed quotas, modality dropout; no fabricated availability. Candidate top budget before editorial scoring; keep broad exploratory lane for quiet and silent moments. Calibrate on dev (Platt/isotonic only sufficient data); report Brier/ECE and subgroup errors. No proxy label transfers to approval. Contrastive retrieve necessary support then NLI/LLM with evidence IDs and contradiction check; constrained boundary enumerator hard rejects missing essential spans, clipping words, unsupported visual claims; independent human assesses meaning.
Distillation: use permitted teacher with logged input/output/versions, pairwise order and soft scores; sample uncertain cases, diverse quiet, same-speaker/word wrong context hard negatives. Pairwise soft labels only when meaningful; no synthetic reasons as truth. Human reviewer not teacher; holdout never teacher training. Assess teacher-v-human, student-v-human, source-level leakage, negative mining and feedback bias. Teacher tokens cost and provider terms gate. No RL or large generative DPO until scalar head plateaus and real preference dataset exists.
