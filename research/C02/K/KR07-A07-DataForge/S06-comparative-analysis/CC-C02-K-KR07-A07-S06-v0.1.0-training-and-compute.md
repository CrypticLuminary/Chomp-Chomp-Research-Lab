# Training plan and resource analysis
Plan A no training: deterministic ASR/diarization, retrieval, candidate rules, selective structured reasoning; lowest implementation and data risk, API/runtime dependency. Establish quality/cost baseline.
Plan B frozen encoder heads: small BCE/ranking/temporal classifier; needs 100 schema checks then 500–1000 independent examples, CPU head; feature extraction separate. Best marginal experiment, not presumed better.
Plan C LoRA/QLoRA: changes contextual representation and structured decisions; needs several thousand trustworthy examples or weak replay then human refinement. 1–2B 4-bit CUDA, 2–4K context initial; adapter optimization cheaper than full fine-tuning but activations still large. Try only if head plateau with statistically credible gap. Distill ranking before text generation; human validation.
Plan D full multimodal training: separate encoders + large generator training not justified; substantial data, hardware and provenance, weak failure isolation. Reject now. Hybrid architecture D (architecture taxonomy, distinct from plan D): independently cached frozen text/audio/visual, per-task heads, RRF/calibration and selective reasoning. A separate models cost repeated encoding; B shared text encoder with task heads reuses compute but task conflict and missing modality require masks; C single VLM is expensive and hard to debug; D hybrid is cheapest flexible experiment. Keep text and vision separate first; compare early fusion vs late fusion at equal proposal minutes and compute. No universal superiority claimed.
Hardware envelope (planning ranges, not measured): CPU 8–16GB host RAM MiniLM/E5 and head, local ASR int8; CLIP/HuBERT sequential batch1 on 16GB recommended, CPU latency unknown; no 4bit Unsloth promise. 8GB GPU: small encoders, 1–2B quantized inference at short context; head train cached; 1B QLoRA short context possible but uncertain. 12GB: larger batches and short-context 1–2B QLoRA candidate; 16GB T4: fp16 not native bf16, CUDA/bitsandbytes compatibility verify; 1B QLoRA at 2–4K first, 8K OOM risk; 24GB: 1B 8K candidate and 2B short QLoRA; 8B 4bit inference with controlled context, no guarantee. Larger hosted A100/H100 40/80GB: chapter pipeline or longer context, only if approved. API alternative only bounded selective reasoning, price not quoted because no provider chosen/authorized. No paid calls or jobs.
