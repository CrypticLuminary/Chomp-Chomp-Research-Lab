# Source screening
Rhapsody v2 2025-09-07 https://arxiv.org/html/2505.19429v2 : 13,364 podcasts, 90 channels; author-reported 2,467 positive test episodes: F1 text QLoRA .163, DVA .175, HuBERT .197, GPT-4o .057, Gemini text .065. These are replay-bin macro metrics, not human clip quality. See source audit. Chapter-Llama https://arxiv.org/abs/2504.00072 (2025) reports chapter overlap F1 45.3 vs 26.7; not boundary accuracy/clip closure. NEST https://aclanthology.org/2026.emnlp-main.2512/ reports 1005 full films with ~103 events each; retrieval availability remains unresolved. QVHighlights https://github.com/jayleicn/moment_detr supplies query-conditioned moments/saliency, not spontaneous clip worth. FSD50K https://arxiv.org/abs/2010.00475 provides 51,197 multilabel sound clips, not interest. QMSum https://github.com/Yale-LILY/QMSum query-based meeting summaries; retrieval evidence proxy. UR-FUNNY https://github.com/ROC-HCI/UR-FUNNY TED-style humor; not free-form livestream preference. No benchmark number is comparable across these objectives.
Other sources for experiment concepts: LoRA https://arxiv.org/abs/2106.09685, QLoRA https://arxiv.org/abs/2305.14314, distillation https://arxiv.org/abs/1503.02531, DPO https://arxiv.org/abs/2305.18290. These are candidate method references, not independently reproduced. For scalar ranking use pairwise logistic/Bradley-Terry, not DPO over arbitrary clips. DPO applies when a generative model produces competing responses conditioned on same prompt. RL cannot fix invalid reward; defer.
Dataset inventory records direct supervision only for original label target; external labels never serve as gold editorial approval.
