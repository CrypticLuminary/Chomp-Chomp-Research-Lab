# S04 — Proposed competing mechanisms (not trained)
Let x be candidate, c retrieved source evidence, a audience profile; u(x,c,a) editorial utility, m modality mask, r replay weak label. Distinguish r and human approval y. 
A zero-shot: structured LLM(x,c,a) -> hypothesis,evidence,uncertainty; no supervised loss; bounded calls O(N/W), verification O(BR). Failure hallucination/cost.
B frozen encoders: h_i=concat(E_text(x),E_audio(x),E_visual(x),m); local temporal head f(h_{i-k:i+k}); masked BCE(y) or ordinal; O(Nkd) local head plus encoder cost; risk weak labels/ASR.
C PEFT: marker embeddings plus projected audio; BCE on replay pretraining then separate human head. Attention O(T²) per window; truncation/alignment and transfer risk. Rhapsody actual unweighted BCE, not preference.
D pairwise Bradley-Terry: L=-log sigmoid(u_i-u_j) for human preferred i>j, ties separate; matched audience and context; O(P) comparisons, cannot calibrate absolute abstention alone.
E MIL: bag probability 1-product(1-p_i) or max pooling, bag-level BCE; O(N) head; nonlocal weak labels may assign wrong event; bag negative only if comprehensively reviewed.
F multitask: L=sum_j lambda_j mask_j L_j; separate replay, human preference, humor, information, context closure; missing labels mask, not zeros; negative transfer test.
G generative explanation: generate free text reason with cited event/context IDs, conditional token NLL for approved rationales; verify source support, explanation quality not measured preference.
H retrieval: embed event/description, find approved/rejected exemplars; similarity weighting or contrastive InfoNCE; approximate nearest neighbors, creator leakage/novelty risk.
I hybrid: union independently ranked proposals with exploration reserve, contextual review only B; cost O(N cheap + B expensive). Matched-budget recall; no consensus requirement; test routing risk.
No hard-coded weights as final quality. Learn audience preferences, separate confidence and value, gate faithfulness/closure; abstain when no approved candidates. All dimensions optional, single strong reason sufficient. Pseudocode: for lane in observed_lanes: propose(units,lane); union + event dedup + reserve; retrieve dependencies; verify; rank approved; return <=3. Complexity depends encoder and source duration; actual compute unmeasured.
