Paper https://aclanthology.org/2020.coling-main.6/ ; pinned https://github.com/tannerbohn/AutomaticPullQuoteSelection/blob/74d33a4407ce436a46d33ed8b5e66421168a534c/

Per-article normalization risks relative scoring and no absolute abstention. No training/checkpoint/rights verification.
## PDVC (ICCV 2021)
Paper https://openaccess.thecvf.com/content/ICCV2021/html/Wang_End-to-End_Dense_Video_Captioning_With_Parallel_Decoding_ICCV_2021_paper.html ; pinned https://github.com/ttengwang/PDVC/blob/0b025c84f42fe27da51c312e8871c4b19628a04c/
- pdvc/matcher.py:51–121 computes class cost from focal-like positive/negative terms, L1 box cost and negative GIoU, uses Hungarian linear_sum_assignment; optional many-to-one RL indices. pdvc/criterion.py:46–123 sigmoid focal classification, Gaussian-mask event count loss, L1 temporal regression, GIoU and self-overlap; auxiliary layer matching. Event count predicts event cardinality not desirable highlights. Inspect caption head and released weights later; source not run.
- Adapt event description and independent visual core generation; distinguish generic events from interesting events; dense captions can miss silent comedy or subtle state changes, test recall.
