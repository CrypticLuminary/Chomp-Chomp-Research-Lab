| Scenario | Expected failure | Mechanism to test |
|---|---|---|
| Quiet motivational speech | peak ranking | semantic lane / pull-quote |
| Qualified controversy | quote salience | retrieve qualification + faithfulness gate |
| Sarcasm | isolated sentiment | speaker/context retrieval |
| Neutral absurdity | prosody | incongruity explanation |
| Silent visual joke | transcript | visual event lane |
| Loud routine gameplay | excitement | human hard negatives |
| Nested story lesson | fixed bins | overlapping L2 core and support |
| Calm emotional account | intensity | cause/outcome extraction |
| 30-min callback | local windows | long memory dependency |
| Routine VOD | forced top-k | absolute acceptance + abstention |
| Gameplay no chat | chat-first | independent visual/semantic lane |
| Unfamiliar activity | closed taxonomy | free-form event reason + exploration |
| Famous ordinary vs unknown insightful | creator popularity leakage | blind creator, creator-disjoint eval |
| Audiences disagree | scalar global score | audience-conditioned pairwise ratings |
