# Chomp-Chomp Research Lab

Shared research knowledge base for Chomp-Chomp. Production code lives in [AI_Clipper-Chomp-Chomp-](https://github.com/CrypticLuminary/AI_Clipper-Chomp-Chomp-).

**Current cycle:** C02 · **Phase:** K (knowledge gathering). This public repository contains research records, not private footage, credentials, gated dataset contents, or model weights without redistribution rights.

Start with [AGENTS.md](AGENTS.md), the [naming convention](governance/NAMING-CONVENTION.md), [evidence standard](governance/EVIDENCE-STANDARD.md), [review protocol](governance/REVIEW-PROTOCOL.md), [task registry](registry/tasks.yaml), and [roadmap](roadmap/MASTER-ROADMAP.md).

Each agent owns a task directory and an independent branch. Push incremental checkpoints; cite other agents' findings with stable IDs and pinned commit links. Main contains shared governance and reviewed research; a draft branch is not approval. No production changes are authorized by a research report alone.
