# Contributing

1. Read AGENTS.md and registry/tasks.yaml.
2. Branch from main (or resume your existing task branch). Record base SHA.
3. Write only in your assigned directory. Use the templates and naming rules.
4. Commit and push coherent checkpoints after each meaningful substage.
5. Submit a draft PR; include findings, evidence links, limitations and reproduction commands. Do not self-merge.
6. Coordinator records approval, changes requested, or rejection; only reviewed material is merged.
